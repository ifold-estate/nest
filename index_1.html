Nest Thermostat Integration

A private home automation app for the Ifold Estate.

This app connects the Google Nest thermostats installed at the Ifold Estate to the household's own, self-hosted Home Assistant server. It uses Google's Smart Device Management API so the owner can see room temperatures and heating status, and adjust heating set-points, alongside the rest of the home's heating controls.

Who it is for

The app is used only by the owner of the Ifold Estate, for the thermostats in their own home. It is not offered to the public, and nobody else can sign in to it.

What it does

  • Reads each thermostat's current temperature, humidity, mode, set-point and heating status.
  • Changes heating mode and set-points when the owner asks it to.
  • Shows this information on the owner's private Home Assistant dashboard.

Privacy

Data from the thermostats stays on the owner's own Home Assistant server and is never sold or shared. Read the full privacy policy.
